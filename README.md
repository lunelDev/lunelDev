## About

Unity/C# 기반 센서 인터랙션과 웹 풀스택을 함께 다루는 개발자입니다.
BLE IMU, Leap Motion, Kinect, Leia 3D, MediaPipe 같은 입력을 게임 로직·애니메이션·사용자 화면으로 연결해 운동, 재활, 교육 콘텐츠를 구현해 왔습니다.

현재는 언어재활 디지털 헬스케어 제품에서 Next.js/React 기반 클라이언트, 재활 콘텐츠 화면, 훈련 기록 흐름을 개발하고 있습니다.

## AI Workflow

AI 도구를 단순 코드 생성기가 아니라 작업 흐름을 정리하고 검증하는 보조 시스템으로 사용합니다.

- `Context`: Obsidian AI-Wiki에 프로젝트 규칙, 작업 로그, 반복 이슈를 기록
- `Design Review`: 요구사항 분해, 예외 케이스 점검, 구현 방향 비교에 활용
- `Implementation`: 반복 코드, API 연결, UI 개선 초안을 빠르게 만들고 직접 수정
- `Verification`: 빌드, 화면 확인, 회귀 포인트 점검으로 결과물을 검증
